# Crescent Attendance & Payroll — recovered source snapshot

Recovered/reconstructed from the four files copied from the Vercel deployment.

## Local run
- Install Node.js LTS.
- Run `npm install`
- Run `npm run dev`
- Open `http://localhost:3000`

## Important scope notes
This is a recovery snapshot, not a complete production release. Employee Master is held in browser memory only and is not saved to Supabase. Attendance, Missing Punch Report, Payroll Import, Salary Bill and Payslips are placeholders in this recovered version. No Supabase credentials are included. Test locally before deploying.
